4. **Features** (4 mins): Deep dives with use cases

6. **Proof** (2 mins): Traction, achievements, testimonials

## 💡 ADVANCED PRESENTATION HACKS

### For Maximum Impact:
1. **Open with data**: "2.2 billion students. Only 10% achieve their career goals. We're changing that."
2. **Use contrast**: Dark slide → bright metric → dark slide (keeps attention)
3. **Tell micro-stories**: Each feature should have a 30-second student narrative
4. **Lean into visuals**: Minimize text per slide, let graphics tell story
5. **Build tension**: Problem (problems) → solution building (features) → resolution (impact)
6. **End with purpose**: "This isn't just a startup. This is a movement to democratize excellence."

### Animation Pacing:
- Don't over-animate; let audience read
- Use animation to guide attention, not distract
- Pair animations with spoken content (animate while you speak)
- 2-3 animations per slide max (more = distracting)
